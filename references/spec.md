# 完整规格与设计原理（references/spec.md）

> 出处：微信视频号「皮皮爱写作」《公众号排版笔记【第62期】· 瑞士国际主义 N° 62》。
> 数值均来自视频画面标注（px 标签）与口播逐字核对。

## 1. 风格定位

| 项 | 内容 |
|---|---|
| 风格 | 瑞士国际主义（International Typographic Style，1950s，瑞士设计招牌） |
| 四大特征 | 非对称、网格、无衬线、左对齐（ASYMMETRIC / GRID / SANS-SERIF / FLUSH LEFT） |
| 适合内容 | 产品介绍、行业观察——想显得专业又不花哨 |
| 在句方便编辑器中 | 「排版主题 → 瑞士国际主义」 |

设计哲学（视频原句）：
- 「对齐，是最便宜的高级感。」
- 「排版不是装饰，而是替读者省力。」
- 「好的版式，让人感觉不到版式。」
- 「颜色只留给真正要紧的地方，其余交给黑白。」
- 「横线负责分段，竖线负责提醒。线条越少，越显得笃定。」
- 「整篇像瑞士表一样精密——真正的精密，是每一行，都从同一个地方开始。」

## 2. 规矩 01 · 全部靠左（FLUSH LEFT）

| 规则 | 值 | 依据 |
|---|---|---|
| 标题/正文/引用对齐 | 左对齐，左边落在同一条线上 | 口播"左边都落在同一条线上" |
| 居中 | 禁止 | 口播"很多公众号喜欢居中，看着端正，可每一行的开头都不在一个地方，眼睛每换一行都得重新找" |
| 目的 | 起点只有一个，眼睛永远回到同一个起点 | 口播 |

## 3. 规矩 02 · 字号差四（TYPE SCALE）

画面刻度标注（尺子图，逐级 +4）：

| 元素 | 字号 | 备注 |
|---|---|---|
| 一级标题 | 32px | 口播"直接32号，正好是正文的两倍" |
| （28px 刻度） | — | 尺子上留空档，保持 +4 均匀刻度 |
| 二级标题 | 24px | |
| 三级标题 | 20px | |
| 引用 | 18px | 口播"引用……字放大到18号" |
| 正文 | 16px | 基准，口播"正文16号" |

- 口播："像尺子上的刻度，一格是一格。""每一级只差一点，读者却能一眼分出层级。"

## 4. 规矩 03 · 黑线横切（HORIZONTAL RULES）

| 规则 | 值 | 依据 |
|---|---|---|
| 二级标题上方 | 压一道 **2px** 黑线 | 画面标注 "2 px" + 口播"二级标题上方压一道两像素的黑线" |
| 分隔线 | 一道 2px 黑线 | 口播"分隔线也是一道黑线" |
| 分隔线上下留白 | **各 50px** | 画面标注 "50 px"（线上、线下各一）+ 口播"上下各空50像素" |
| 语义 | 看到横线，就知道换了一段 | 口播 |

## 5. 规矩 04 · 红线竖点（RED ACCENTS）

| 规则 | 值 | 依据 |
|---|---|---|
| 全篇红色数量 | **一种红** | 口播"全篇只有一种红，留给两道竖线" |
| 一级标题前 | **8px 宽红条**（竖条，高≈标题字高） | 画面标注 "8 px" + 口播"一级标题前，一道8像素的红条" |
| 引用前 | **细红线**（≈2px 宽竖线，高≈字高） | 画面标注"细红线" + 口播"引用前，一道细红线" |
| 语义 | 红色一出现，就是这里要紧 | 口播 |

### 颜色取样（2026-11-23 从视频画面逐像素采样）

| 用途 | RGB | 建议 CSS |
|---|---|---|
| 红条/细红线 | (208, 0, 19) | `#D00013` |
| 标题/正文文字 | (17, 17, 17) | `#111111` |
| 背景 | (255, 255, 255) | `#FFFFFF` |
| 小注/元信息 | 浅灰 | `#999999`（示例中"设计周记 11月12日"一类灰字） |

> 红色允许等价替换为设计纯红（如 `#E60012`），但**全篇只能一种红**。

## 7. 反例（视频明确批判 / 观感直接违反）

- 居中排版（"看着端正"是错觉，起点不唯一）
- 居中的项目符号块、参差的"居中缩进"引用
- 色块、渐变、多色强调
- 随手字号（破坏 +4 阶梯）

## 8. 原视频口播逐字稿（存档）

瑞士排版，从不居中。靠左对齐，是上世纪五十年代瑞士设计的招牌。公众号照着排，整篇像瑞士表一样精密，靠的是四条规矩。
第一条，全部靠左。标题、正文、引用，左边都落在同一条线上。很多公众号喜欢居中，看着端正，可每一行的开头都不在一个地方，眼睛每换一行都得重新找。靠左，眼睛永远回到同一个起点。
第二条，字号差四。正文十六号，往上每一级加四：二十、二十四。最顶上的一级标题，直接三十二号，正好是正文的两倍。像尺子上的刻度，一格是一格。
第三条，黑线横着切。二级标题上方，压一道两像素的黑线。分隔线也是一道黑线，上下各空五十像素。看到横线，就知道换了一段。
第四条，红线竖点。全篇只有一种红，留给两道竖线。一级标题前，一道八像素的红条；引用前，一道细红线，字放大到十八号。红色一出现，就是这里要紧。
四条规矩，记成四个词：全部靠左、字号差四、黑线横切、红线竖点。这套排版，在句方便里叫瑞士国际主义。写产品介绍、行业观察，想显得专业又不花哨，可以换上它。真正的精密，是每一行，都从同一个地方开始。
